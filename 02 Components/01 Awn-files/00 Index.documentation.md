# Описание назначения основных файлов

Данные файлы создаются в корне проекта (хранилища)

## awn.dependencies.md

Системные зависимости. В данный файл записываем все установленыне зависимости на сервере что бы не забыать.
Файл создается при установке изменении зависимостей агентом.

Если файл отсуствует - берем используем его.
Смотреть шаблон [awn.dependencies.template](awn.dependencies.template.md)

## awn.registry

Рабочий реестр `*.node.md` vault.  Реестр нод и других файлов - создается (обновляется) по явному запросу пользователя

Работает как **таблица маршрутов**: входящий запрос сопоставляется с `AWN-TRIGGERS` нод и определяет, какие файлы добавить в контекст агента.

Смотреть шаблон [awn.registry.template](awn.registry.template.md)
