Базовые CRUD операции при работе с нодами. Остальные детальные правила и назначения уже определяются в самой ноде

1) Спроси пользователя о чем будет нода
2) Если папка существует - создать в ней соответсвующий файл
3) Определи тип ноды
4) Предложи создать соответстующий раздел и файл ноды
5) Удаление производи с разрешения пользователя
