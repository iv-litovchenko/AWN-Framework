# Обновление документаций

Команда - обнови документацию

1) Найди все файлы *.documentation.md*
2) Приоритет отдавай AWN-фреймворку в начале выходного файла
3) Нумерацию параграфов задавай на основе древовидного содержимого и влженности папок и файлов
4) Собери (контатенция) содержимое всех файлов в виде оглавления книги 
5) К каждому файлу делай ссылку на источинк (start, end) что бы было понятно откуда пришла глава
6) Выходной файл сделай в Хранилище/<Папка AWN-Freamwork/05 Required/Documentation.combined.md
7) Ссылки на файлы заменяй на ссылку параграфа сгенерированного документа если она есть
8) Сформулируй оглавление в начале документа

Нумерацию параграфов и вложенность делаем согласно древовидной структуре расположнения каталогов. Документация подружается кжадый раз при старте агента через файл AGENTS.md
