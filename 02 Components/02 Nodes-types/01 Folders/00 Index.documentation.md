## Структура папок ноды

В компонентах типа "папка" допускается следующая структура (папки создаются по мере необходимости)

```
Assets/ содержит вложения к записям ноды (по умолчанию раскладывается по папкам текущей даты YYYY-MM-DD/)

Content/ содержит записи ноды с внешней памятью
Content/Logs для логов
Content/Trash

References/ Это одна из самых полезных папок в системе. Она предназначена для **«внешних знаний»** — всего того, что ты не создаёшь сам, а собираешь из внешнего мира.

Branches/  (Children/) - содержит дочерние ноды
Parts/ (nodes - аналог Clasess/) - содержит ноды-части
Scripts/ содержит разработанные скрипты (bash, python, другие)

Inbox/ папка по умолчанию в для входящих данной тематики (сырые заметки - не актуально - пользователь создает область "Входящие"

Templates/ Все шаблоны (Skeleton, Node, Memory, Sidecar и т.д.)
Views/ Дашборды, канбаны, mindmap-обзоры, списки
```

Свойство AWN-CORE-CHILDREN-ALLOW - описыает разрешено ли создание дочерних нод 

Папки создаются по мере необходимости. Корневое рабочее дерево для всех областей — **`awn-spaces/`** (не засорять корень Vault; префикс `awn` отделяет фреймворк от стороннего кода в workspace).


| Inbox/      | Входящий поток (capture) «Входящие» Всё новое, что прилетает. Как почтовый ящик. Здесь бардак разрешён. Сырая ссылка на статью или голосовое «послушал подкаст про атомные привычки»                                                                                                                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Content/    | Внутренняя память нод и системы «Внутреннее содержание / Память» Это твои собственные наработки, размышления, история работы с нодами. Личная память системы. Здесь лежат:<br><br>- Записи внутри нод (*.node.content.md)<br>- Логи обсуждений<br>- Insights и выводы<br>- Контекст по проектам и пространствам<br><br>Твои личные выводы: «Как я применяю это в своей жизни», трекинг привычек, размышления |
| References/ | Внешние знания (библиотека) «Справочники / Внешние источники» Это библиотека переработанных чужих материалов. То, что ты взял снаружи и сделал полезным. Конспект книги Джеймса Клира + ключевые цитаты + PDF                                                                                                                                                                                                |
| Temporary/  | Это временное рабочее пространство — «черновой стол», где можно быстро сбрасывать вещи, которые ещё не имеют постоянного места. **Быстрые эксперименты**  **Промежуточные материалы** <br>- Временные файлы, изображения, скриншоты, экспортированные данные                                                                                                                                                 |


### Папки внутри Space (по необходимости)

| Папка / файл                                                   | Назначение                                                                        |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `assets/`                                                      | Вложения, медиа (к ним — Sidecar `*.sidecar.md` рядом или по соглашению области). |
| `inbox/`                                                       | Сырые Note: `*.note.md`.                                                          |
| `notes/`                                                       | Note вне inbox (если нужен отдельный поток).                                      |
| `pages/`                                                       | Page: `*.page.md`.                                                                |
| `databases/<type>/`                                            | Row: `*.row.md`; `<type>` = имя подпапки (`default`, `calendar`, …).              |
| `views/<type>/`                                                | View: `*.view.md`.                                                                |
| `parts/` или `nodes/`                                          | Группировка Part `*.node.md` (опционально).                                       |
| `cron/`                                                        | Part-ноды автоматизации.                                                          |
| `scripts/`                                                     | Вспомогательные скрипты (External или не ноды).                                   |
| `templates/`                                                   | Заготовки.                                                                        |
| `_index.node.volume.md`                                        | Volume якоря Space (рядом с `_index.node.md`).                                    |
| `<name>.node.md`, `<name>.node.volume.md`, `<name>.resources/` | Part и спутники.                                                                  |
| `config.md`                                                    | Настройки области; может агрегироваться в глобальный конфиг (отдельное правило).  |

### Вариант `content/`

Если хочешь сгруппировать потоки памяти:

- `content/notes/` — эквивалент части `notes/` / `inbox/` по соглашению области.
- `content/<тип>/` — произвольный подтип контента.

Явно зафиксируй в `_index.node.md` области, какой вариант используется (**плоские папки** vs **`content/`**).
