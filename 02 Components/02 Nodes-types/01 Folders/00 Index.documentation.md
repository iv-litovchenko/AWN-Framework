## Структура папок ноды

В компонентах типа "папка" допускается следующая структура (папки создаются по мере необходимости)

| Папка/Файл            | Назначение                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Assets/               | содержит вложения к записям ноды (по умолчанию раскладывается по папкам текущей даты YYYY-MM-DD/)                                                                                                                                                                                                                                                                                                                                                    |
| Children/ (Branches/) | содержит дочерние ноды                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Parts/ <br>           | (nodes - аналог Clasess/) - содержит ноды-части (ноды части не обязательно располагать в этой папке)                                                                                                                                                                                                                                                                                                                                                 |
| Scripts/              | содержит разработанные скрипты (bash, python, другие)                                                                                                                                                                                                                                                                                                                                                                                                |
| Inbox/                | папка по умолчанию в для входящих данной тематики (сырые заметки - не актуально - пользователь создает область "Входящие" Входящий поток (capture) «Входящие» Всё новое, что прилетает. Как почтовый ящик. Здесь бардак разрешён. Сырая ссылка на статью или голосовое «послушал подкаст про атомные привычки»                                                                                                                                       |
| Content/              | содержит записи ноды с внешней памятью. Внутренняя память нод и системы «Внутреннее содержание / Память» Это твои собственные наработки, размышления, история работы с нодами. Личная память системы. Здесь лежат:<br><br>- Записи внутри нод (*.node.content.md)<br>- Логи обсуждений<br>- Insights и выводы<br>- Контекст по проектам и пространствам<br><br>Твои личные выводы: «Как я применяю это в своей жизни», трекинг привычек, размышления |
| Content/Artifacts/    | Складыть сюда сгенерированные данные (выходные данные) в резуальтате работы агента - сбор аналитических данных - саммари - спарсенные данные - аналог Artifacts                                                                                                                                                                                                                                                                                      |
| Content/Trash         | корзина для удаленного контента                                                                                                                                                                                                                                                                                                                                                                                                                      |
| References/           | Это одна из самых полезных папок в системе. Она предназначена для **«внешних знаний»** — всего того, что ты не создаёшь сам, а собираешь из внешнего мира. Внешние знания (библиотека) «Справочники / Внешние источники» Это библиотека переработанных чужих материалов. То, что ты взял снаружи и сделал полезным. Конспект книги Джеймса Клира + ключевые цитаты + PDF                                                                             |
| Temporary/            | Это временное рабочее пространство — «черновой стол», где можно быстро сбрасывать вещи, которые ещё не имеют постоянного места. **Быстрые эксперименты**  **Промежуточные материалы** <br>- Временные файлы, изображения, скриншоты, экспортированные данные                                                                                                                                                                                         |
| Logs/                 | для логов                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Templates/            | Все шаблоны (Skeleton, Node, Memory, Sidecar и т.д.)                                                                                                                                                                                                                                                                                                                                                                                                 |
| Vision/               | Дашборды, канбаны, mindmap-обзоры, списки - здесь размещяются Vision - Views - виды предтавления данных                                                                                                                                                                                                                                                                                                                                              |
| .env                  | Сюда выносить все настраиваемые даные для скриптов                                                                                                                                                                                                                                                                                                                                                                                                   |
|                       |                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

Данные типы нод "папка" не обязательна — если их нет, агент работает с нодами напрямую по триггерам либо с контентом.

| Папка / файл                                                   | Назначение                                                                       |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `<name>.node.md`, `<name>.node.volume.md`, `<name>.resources/` | Part и спутники.                                                                 |
| `config.md`                                                    | Настройки области; может агрегироваться в глобальный конфиг (отдельное правило). |
