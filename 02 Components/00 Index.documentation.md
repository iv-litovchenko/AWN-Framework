# Система состоит из компонентов (нод и памяти)

Есть несколько типов нод (уровней слоя)

- нода-папка (описывает что это за папка и как работать с данными в ней)
- ноды-части - когда сложная нода разбивается на части
- память (воспоминание прикрепленное к ноде) - нодой не является
- все остальные файлы в системе

Одна нода - одна задача.
